NAME

fkpt2 - compute one-loop redshift-space power spectrum multipoles

SYNOPSIS

fkpt2 [parameter-file] [name=value ...]

DESCRIPTION

fkpt2 computes one-loop redshift-space multipoles from a linear power spectrum. The default build includes LCDM, Hu–Sawicki f(R), DGP, and massive-neutrino models and can compute real-space CLPT correlations and Gaussian Streaming Model multipoles.

A parameter file accepts name = value or name value. The characters # and % start comments outside quoted values. Command-line settings override entries in the file.

OPTIONS

--help
Show the parameter list and defaults for the current build.
options=print-models
List the available gravity models.
fnamePS=path
Read the linear spectrum at zout. The first two columns give k in h/Mpc and P(k) in (Mpc/h)³.
model=name
Select the gravity model. Use model=HS fR0=1e-5 to select F5.
clpt=true
Compute real-space correlations and displacement correlators.
gsm=true
Compute Gaussian Streaming Model multipoles and their CLPT inputs.
rootDir=directory
Set the output directory. The default is Output.
numberThreads=count
Set the thread count for an OpenMP build.

FILES

rsd_multipoles.txt
Wave number and monopole, quadrupole, and hexadecapole of the power spectrum.
tmp/
Resolved parameter values and, when verbose_log=1 is set, a run log.

EXAMPLES

fkpt2 model=HS fR0=1e-5 rootDir=Output_F5
fkpt2 run.ini fR0=1e-6 rootDir=Output_F6
fkpt2 gsm=true

With the CLASS addon linked, use a combined [class] and [fkpt2] parameter file.

fkpt2 scripts/class_fkpt2.ini
