Parameters
==========

This table is generated from the same definitions used for runtime defaults,
alias lookup, and ``fkpt2 --help``. The CLI also accepts ``paramfile`` or a
positional parameter filename. Python accepts ``paramfile`` as a keyword or
as an entry in the options mapping.

For model settings see :doc:`models`. For configuration-space bias, EFT, and
quadrature settings see :doc:`fkpt2-clpt` and :doc:`fkpt2-gsm`.
