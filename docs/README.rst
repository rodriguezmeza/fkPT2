fkPT2 documentation
===================

fkPT2 predicts one-loop redshift-space power spectrum multipoles and
configuration-space correlations from a linear spectrum.

* `Start with the fkPT2 manual <index.rst>`_ or the `quickstart <quickstart.rst>`_.
* `Build the CLI or Cython extension <installation.rst>`_.
* `Generate spectra with CLASS <class_workflow.rst>`_.
* `Build and publish the Sphinx manual <publishing.rst>`_.

See the `project README <../README.md>`_ for the build commands, regression
tests, and citation information.
